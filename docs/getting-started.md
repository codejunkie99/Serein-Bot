# Getting started

[← Back to README](../README.md)

## Before you start

- A Mac with macOS 14 or later.
- At least one AI app signed in on your Mac, or a local model server. See [Agents and models](agents-and-models.md).
- Serein, downloaded from [serein.pro](https://serein.pro/#download) or [built from source](building-from-source.md).

## First run

1. **Connect an AI app.** Pick an app and follow its sign-in. Choose **Set up later** to look around first.
2. **Let Serein work in your apps.** This step is optional. Grant Accessibility and Screen Recording if you want Serein to click, type and read the window of the app you name. Select **Open Serein** to continue with nothing granted.
3. **Ask.** Press <kbd>⌘E</kbd> and type a request.

## Try these

- “Remind me at 5 pm to stretch.” Serein shows the reminder in chat.
- Open a page and ask “Summarize this page in three bullets.”

## Already use another copy of Serein?

Quit the other copy first. Both use `~/Library/Application Support/Serein/Library`.

If an assistant used a Serein-hosted computer before, choose a replacement in **Settings → Serein’s computer**. Serein waits for your choice before it runs that assistant's computer tasks.

## Updates

If you build from source, updates are manual. To use a newer checkout, quit Serein, then build it again.
